[h1]A trained model runs the AI's strategy[/h1]

JevAI uses a locally running DeBERTa-v3-large model to choose strategic priorities for AI countries. It changes AI priorities, not combat bonuses, and excludes human-controlled countries. The native game AI still handles the units.

This release includes [b]OpenVINO models for CPU and Intel NPU[/b], plus an [b]experimental multiplayer relay[/b]. The model is a small supervised continuation on verified game outcomes. It is not proven stronger in live games; corrected offline evaluation still shows weaknesses.

[h2]What it decides[/h2]
The six postures are defensive buildup, industrial expansion, armored offensive, air power, naval power and total war economy. They affect AI production, unit mix, factory ratios and construction priorities.

The model predicts [b]three-month outcomes[/b]. That prediction horizon is separate from the decision frequency you choose in game: weekly, monthly or every three months. Choose major powers, all eligible AI countries (20+ factories), or off.

[h2]Install and run[/h2]
Windows 10/11 64-bit and HOI4 1.19 are required. Subscribe, enable JevAI in the launcher playset, and open:
[b]<Steam library>\steamapps\workshop\content\394360\{id}\runner[/b]
[list]
[*][b]Automatic:[/b] run install.cmd once to prepare the model and add the runner to Windows Startup. uninstall.cmd removes that startup integration.
[*][b]Manual:[/b] open jevai.exe before the game and keep its console running. No separate Python install is needed.
[/list]
The model files are included (the item is a few GB). First compilation depends on hardware; the log reports progress and timeouts. Cached starts are faster. NPU compilation has a ten-minute limit, CPU compilation five minutes; NPU failures fall back to CPU. CPU decisions can take time across many countries, so monthly or quarterly updates are usually more practical than weekly updates for all countries.

Log: [b]%LOCALAPPDATA%\jevai\jevai.log[/b]. If no decisions appear, check that the playset enabled JevAI and read the runner's load/compile and missing-telemetry messages. Overhauls may replace scripts; the runner adjusts load-order dependencies for the next launch. The model has seen several overhaul settings, but compatibility and strength are not guaranteed for every mod.

[h2]Experimental multiplayer[/h2]
[b]Two-machine gameplay acceptance has not been completed. Late or missing orders can cause desync. Use this feature only if all players accept that limitation.[/b]
[list]
[*]Every player needs the same JevAI build, playset and a running companion runner.
[*]The host runs [b]host.cmd[/b] once and shares its code.
[*]Other players run [b]join.cmd[/b] and enter the code. Configure roles before starting the session.
[*]Only the host makes model decisions during multiplayer. Clients receive the same dated order file through a Steam lobby. No configured role means JevAI stays off in multiplayer.
[*]If Steam integration fails, inspect the relay log. The CLI supports --steam-api for a compatible stock Steam API DLL; do not replace game files blindly.
[/list]
Single-player decisions run locally without a multiplayer relay. CPU/NPU numerical equivalence has been checked on sample inputs; that does not establish multiplayer synchronization or improved gameplay.

[h2]简体中文[/h2]
JevAI 用本地模型为 AI 国家选择六种战略姿态：防御建设、工业扩张、装甲攻势、空中力量、海军力量、全面战争经济。它只改变 AI 优先事项，不提供战斗加成，不操控玩家国家；具体单位仍由游戏原生 AI 指挥。

本版包含 [b]CPU / Intel NPU OpenVINO 模型[/b]和[b]实验性多人功能[/b]。经过少量真实游戏结果后训练，但尚未证明能提升实际游戏表现。默认预测未来[b]三个月[/b]，与开局选择的每周／每月／每三个月决策频率不同。

订阅并在启动器启用后，打开 [b]<Steam 库>\steamapps\workshop\content\394360\{id}\runner[/b]。运行一次 [b]install.cmd[/b]可准备模型并加入开机启动；[b]uninstall.cmd[/b]移除该启动方式。也可每次游戏前手动打开 [b]jevai.exe[/b]并保持窗口运行。需要 Windows 10/11 64 位、HOI4 1.19，无需另装 Python。首次编译时间取决于硬件，NPU 最长十分钟、CPU 五分钟；NPU 失败可回退 CPU。CPU 指挥较多国家时，建议每月或每三个月决策。

[b]多人尚未完成双机实测，命令迟到或丢失可能导致不同步。[/b]所有玩家使用相同版本和播放集并运行伴随程序；主机运行 [b]host.cmd[/b]分享代码，其他玩家运行 [b]join.cmd[/b]输入代码。请在开局前设定角色。多人局只有主机做模型决策，客户端通过 Steam 接收带日期的同一命令文件；未配置角色时多人局不启用 JevAI。

日志：[b]%LOCALAPPDATA%\jevai\jevai.log[/b]。本版的 CPU/NPU 数值一致性检查不能代替双机同步测试，也不代表模型已经更强。
