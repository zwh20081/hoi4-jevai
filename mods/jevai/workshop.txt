[h1]A trained model runs the AI's strategy[/h1]

JevAI lets a neural network choose the strategic posture of AI countries. On every update, a DeBERTa-v3-large model trained on data from 33 observer games reads each country's situation: factories, divisions, manpower, stability, war support, strength ratios, enemies, allies and neighbours. It predicts how each of six postures would work out over the next six months, and the mod applies the best one:

[list]
[*]defensive buildup
[*]industrial expansion
[*]armored offensive
[*]air power
[*]naval power
[*]total war economy
[/list]

A posture changes only what the AI prioritizes: unit mix, production, factory ratios and construction. It gives no bonuses, and your own country is never touched.

[h2]Setup[/h2]
Subscribe first. The item is about 2.5 GB because the model is included. Open [b]<your Steam library>\steamapps\workshop\content\394360\{id}\runner[/b] (for example C:\Program Files (x86)\Steam\steamapps\workshop\content\394360\{id}\runner), then choose how to start the companion runner:

[list]
[*][b]Start automatically with Windows:[/b] Run [b]install.cmd[/b] once. It copies the runner to %LOCALAPPDATA%\jevai, prepares the model (about 2 minutes on an Intel NPU, a few seconds on a CPU), starts it now, and adds it to Windows Startup. To stop automatic startup and the running copy, run [b]uninstall.cmd[/b] from the same Workshop folder.
[*][b]Start manually each time:[/b] Double-click [b]jevai.exe[/b] in the runner folder before launching the game. Keep its console window open while playing; press Ctrl+C in that window when finished. Repeat this each time you play. No startup entry is created.
[/list]

If Windows SmartScreen warns about the unsigned jevai.exe, choose "More info", then "Run anyway". Start Hearts of Iron IV from the Paradox launcher with JevAI in your playset. The runner waits for the game, steers it while it runs and waits again when you quit. It uses no network.

[h2]In game[/h2]
At the start of each game, two events ask who the model commands and how often it decides:
[list]
[*][b]Major powers only[/b], [b]All AI countries[/b] (those with at least 20 factories) or [b]None[/b] (vanilla AI)
[*][b]Every week[/b], [b]Every month[/b] or [b]Every 3 months[/b]
[/list]

The model is prepared before any game (by install.cmd, or by jevai.exe when you start it), so games load it in seconds, before HOI4 has finished loading. If the NPU compile fails or takes more than 10 minutes, JevAI switches to the CPU for good (run jevai.exe --device NPU to try the NPU again). A decision takes about 1.5 seconds per country on an Intel NPU and about 10 seconds on a CPU; the game keeps running meanwhile. On a CPU, weekly decisions for all AI countries cannot keep up, so pick monthly or every 3 months there.

The log is %LOCALAPPDATA%\jevai\jevai.log: one line per update, and a line explaining the problem if the game logs nothing for JevAI (JevAI missing from the playset, two mods named JevAI, or an overhaul mod that replaces its scripts).

[h2]Good to know[/h2]
[list]
[*]Windows 10 or 11, 64-bit, and Hearts of Iron IV 1.19. The model runs on an Intel NPU (Core Ultra) if you have one, otherwise on the CPU.
[*]Overhaul mods: JevAI puts itself after them in the load order, but the model was trained on vanilla 1936 games, so it has not seen other settings.
[*]Multiplayer is not supported: each player's game would read its own orders.
[/list]

JevAI 让训练好的神经网络为 AI 国家选择战略姿态（防御建设、工业扩张、装甲攻势、空中力量、海军力量、全面战争经济）。姿态只改变 AI 的优先事项，不提供任何加成，也不会影响玩家自己的国家。
订阅本模组（约 2.5 GB，含模型），打开 [b]<Steam 库>\steamapps\workshop\content\394360\{id}\runner[/b]，选择一种启动方式：
[list]
[*][b]随 Windows 自动启动：[/b]运行一次 [b]install.cmd[/b]，它会先准备模型（Intel NPU 约 2 分钟，CPU 几秒），然后立即启动后台程序，并加入开机启动。若要移除，运行同一文件夹里的 [b]uninstall.cmd[/b]。
[*][b]每次手动启动：[/b]在开始游戏前双击 [b]jevai.exe[/b]，游玩时保持命令窗口打开；结束后在窗口中按 Ctrl+C。下次游玩需要再次启动。
[/list]
若 SmartScreen 提示，请选择“更多信息”→“仍要运行”。在 Paradox 启动器中启用 JevAI 并启动游戏。开局的两个事件依次询问：由模型指挥谁（仅主要国家、所有 AI 国家或不启用），以及多久决策一次（每周、每月或每 3 个月）。

install.cmd（或手动启动的 jevai.exe）会在游戏前准备好模型（Intel NPU 首次约 2 分钟，CPU 几秒），之后每次游戏都能在几秒内加载。若 NPU 编译失败或超过 10 分钟，JevAI 会改用 CPU（运行 jevai.exe --device NPU 可重试 NPU）。每个国家的决策在 Intel NPU 上约 1.5 秒，在 CPU 上约 10 秒，因此使用 CPU 时请选择每月或每 3 个月。日志：%LOCALAPPDATA%\jevai\jevai.log，若游戏没有记录 JevAI 的信息，日志会说明原因（播放集未启用 JevAI、有两个名为 JevAI 的模组，或大型模组替换了它的脚本）。不支持多人游戏。
